# אתר אלון חנין — מערכות דיגיטליות לעסקים

אתר עסקי (one-page, עברית, RTL) שבנוי עם React + Vite + TypeScript + Tailwind CSS,
מוכן לפריסה ל-Cloudflare Pages.

## פיתוח מקומי

```bash
npm install
npm run dev
```

האתר יעלה בכתובת שמודפסת בטרמינל (בדרך כלל `http://localhost:5173`).

## Build לפרודקשן

```bash
npm run build
```

הפלט נוצר בתיקיית `dist/`. אפשר לבדוק אותו מקומית עם:

```bash
npm run preview
```

## פריסה ל-Cloudflare Pages

1. דחפו את הריפו ל-GitHub.
2. ב-Cloudflare Dashboard → **Workers & Pages** → **Create** → **Pages** → **Connect to Git**, בחרו את הריפו.
3. הגדרות ה-build:
   - **Build command**: `npm run build`
   - **Build output directory**: `dist`
   - **Framework preset**: Vite (או None + ההגדרות הידניות למעלה)
4. שמרו ופרסמו. כל push ל-branch הראשי יבנה ויפרוס גרסה חדשה אוטומטית.

### חיבור דומיין מותאם אישית

ב-Pages project → **Custom domains** → **Set up a custom domain**, הזינו את הדומיין
ועקבו אחר ההנחיות (אם הדומיין כבר מנוהל ב-Cloudflare, ה-DNS מתעדכן אוטומטית).

## מבנה הפרויקט

```text
src/
  components/     רכיבי UI כלליים לשימוש חוזר (כפתור, ניווט, פוטר...)
  sections/       הסקשנים של דף הבית (Hero, שירותים, פרויקטים...)
  data/           כל תוכן הטקסט — כאן עורכים את מה שכתוב באתר
  config/         קונפיגורציה: שם המותג, פרטי יצירת קשר
  types/          טיפוסי TypeScript משותפים
  App.tsx         הרכבת כל הסקשנים לדף אחד
```

## איפה לערוך תוכן

כל התוכן שכדאי לעדכן נמצא ב-`src/data/` וב-`src/config/` — אין צורך לגעת ברכיבי React:

| קובץ | מה עורכים בו |
| --- | --- |
| `src/data/siteContent.ts` | כותרת הראשי (Hero), טקסט "העסק גדל", "איך זה עובד", "עליי", טקסט יצירת קשר, ניווט |
| `src/data/services.ts` | 4 השירותים + הערת האינטגרציות |
| `src/data/projects.ts` | **כאן מוסיפים פרויקט חדש** — פשוט מוסיפים אובייקט נוסף למערך |
| `src/data/process.ts` | 5 שלבי העבודה |
| `src/data/differentiators.ts` | הסיבות ב"למה לעבוד איתי" |
| `src/config/site.ts` | שם המותג והתיאור הקצר (אם ירצה שינוי מותג בעתיד) |
| `src/config/contact.ts` | **מספר WhatsApp, אימייל, LinkedIn, GitHub** — ראו הערה למטה |

### הגדרת WhatsApp / Email

ב-`src/config/contact.ts`:

```ts
export const contact = {
  whatsapp: "972501234567", // ספרות בלבד, בפורמט בינלאומי, בלי "+"
  email: "you@example.com",
  linkedin: "https://www.linkedin.com/in/your-profile",
  github: "",
};
```

כרגע ממולאים כאן פרטי הקשר האמיתיים שלך (מייל, טלפון וקישור LinkedIn) לפי קורות
החיים ששיתפת. אם תרצה להשתמש במספר טלפון עסקי נפרד מה-WhatsApp האישי — עדכן כאן.
כל שדה שמושאר ריק (`""`) גורם לכפתור המתאים להיעלם אוטומטית מהאתר, כך שאפשר
תמיד להשאיר שדה ריק בלי לשבור שום דבר.

## החלטות עיצוב מרכזיות

- **טיפוגרפיה**: Frank Ruhl Libre (כותרות) + Assistant (טקסט רץ) — זוג גופנים
  עבריים עם אופי בוטיקי, לא "עוד סטארטאפ עם Rubik".
  אין תלות בפונטים לוקאליים; שניהם נטענים דרך Google Fonts.
- **פלטת צבעים**: אבן חמה (`paper`) + דיו כמעט-שחור (`ink`) + אדום יין עמוק
  (`wine`) כאקצנט מרכזי — רמיזה עדינה לרקע שלך ביין (Soreq Winery, WineOps),
  בלי להיות מילולי מדי.
- **מוטיב ה-Hero**: "תגיות מפוזרות" (Excel / WhatsApp / מייל / פתקים) שמתכנסות
  לכרטיס מסודר אחד — ויזואליזציה ישירה של הבטחת המותג, בלי גרפיקה גנרית.
- **RTL אמיתי**: `dir="rtl"` ו-`lang="he"` על תגית ה-`<html>` עצמה (ב-`index.html`),
  לא טריקים ב-CSS. Tailwind ו-flex/grid מתהפכים אוטומטית בזכות זה.
- **בלי ספריות מיותרות**: אין React Router (לא נדרש לדף אחד), אין ספריית אנימציה
  חיצונית — כל האנימציות הן CSS טהור ומכבדות `prefers-reduced-motion`.

## i18n / אנגלית בעתיד

המבנה תומך בהוספת גרסה אנגלית מאוחר יותר בלי שינוי ארכיטקטורה: כל טקסט כבר
מרוכז בקבצי `src/data/*`, כך שהצעד הטבעי הוא לשכפל את הקבצים האלה ל-`*.en.ts`
ולהוסיף החלפת שפה שבוחרת בין הסטים לפי locale — לא מומש בכוונה בגרסה הראשונה,
כדי לא לסבך דף אחד פשוט.

## מה עוד לא ממומש (בכוונה)

לפי הבריף — נשאר פשוט לגרסה ראשונה, קל להרחיב בהמשך:

- גרסה אנגלית
- עמודי קייס-סטאדי נפרדים לכל פרויקט
- בלוג / מאמרים
- טופס יצירת קשר עם backend (כרגע WhatsApp + מייל ישיר)
- אנליטיקס
- עמוד פרטיות / תנאי שימוש
